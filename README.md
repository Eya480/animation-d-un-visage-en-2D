Animation ou expression d'un visage en 2D:
 
Composer plusieurs expressions faciales ou poses a partir de sprites separes : bouche, yeux/sourcils et visage.

- Les objets des scenes sont nommes "visage", "bouche", "seil1", "seil2", "mouth_oval"
  et "brow_angry".
- Il existe plusieurs scenes : "SampleScene" et "scene 2".
- L'image "cours.png" est utilisee comme ressource.
